# OL Mate Knowledge Base

These files are original starter notes for the OL Mate chatbot and quiz generator.
They are written for Sri Lankan GCE Ordinary Level style revision and cover the
subjects already available in the app.

How this folder works:
- Put `.md`, `.txt`, or `.pdf` files here.
- The chat bot retrieves relevant chunks from these files in real time.
- The quiz generator uses the same knowledge to create MCQs and explanations.
- Keep each file focused on one subject or topic for better retrieval.

Important note:
This pack is a practical revision base, not an official syllabus replacement.
Always compare final teaching coverage with your current school syllabus,
teacher's guide, and textbook.

File guide:
- `mathematics.md`: formulas, worked methods, common problem templates.
- `science.md`: biology, chemistry, physics, environment notes.
- `english.md`: grammar, comprehension, writing, vocabulary.
- `sinhala.md`: language and literature answer patterns in English medium notes.
- `tamil.md`: language and literature answer patterns in English medium notes.
- `history.md`: chronology, causes, effects, answer structures.
- `buddhism.md`: teachings, values, life applications.
- `christianity.md`: teachings, values, life applications.
- `islam.md`: beliefs, practices, values, life applications.
- `hinduism.md`: beliefs, practices, values, life applications.
- `ict.md`: hardware, software, data, networks, safety.
- `commerce.md`: business, accounting, trade, entrepreneurship.
- `geography.md`: maps, climate, resources, population, environment.
- `civic_education.md`: citizenship, rights, duties, democracy, law.
- `common_problem_bank.md`: reusable question formats for chat and quizzes.
