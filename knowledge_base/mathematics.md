# Mathematics Knowledge Base

## Exam Answer Pattern

For any mathematics answer, show the formula or rule first, substitute values
clearly, simplify step by step, and write the final answer with units when
needed. Do not skip working because marks are often awarded for method.

## Number And Arithmetic

Natural numbers are counting numbers. Integers include positive numbers, zero,
and negative numbers. Rational numbers can be written as fractions. Irrational
numbers cannot be written as exact fractions, such as square root of 2.

Order of operations: brackets first, then powers and roots, then multiplication
and division from left to right, then addition and subtraction from left to
right.

Percentage means out of 100. To find a percentage of a value, multiply the value
by the percentage divided by 100. To increase by a percentage, multiply by
1 plus the rate. To decrease by a percentage, multiply by 1 minus the rate.

Ratio compares quantities. If a total is divided in the ratio a:b, the first
share is total x a / (a + b), and the second share is total x b / (a + b).

## Algebra

An algebraic expression uses letters to represent numbers. Like terms have the
same variable part and can be added or subtracted.

Linear equation method:
1. Remove brackets.
2. Collect variable terms on one side.
3. Collect number terms on the other side.
4. Divide by the coefficient of the variable.
5. Check by substitution.

Example: 3x + 4 = 19. Then 3x = 15, so x = 5.

Quadratic equation form: ax^2 + bx + c = 0. Solve by factorisation when simple.
If factorisation is difficult, use x = (-b +/- sqrt(b^2 - 4ac)) / 2a.

Factorisation patterns:
- Common factor: ax + ay = a(x + y).
- Difference of squares: a^2 - b^2 = (a - b)(a + b).
- Perfect square: a^2 + 2ab + b^2 = (a + b)^2.

## Geometry

Angles on a straight line add to 180 degrees. Angles around a point add to
360 degrees. Vertically opposite angles are equal. Corresponding and alternate
angles are equal when lines are parallel.

Triangle angle sum is 180 degrees. An exterior angle of a triangle equals the
sum of the two opposite interior angles.

Pythagoras theorem: in a right-angled triangle, hypotenuse^2 = side1^2 + side2^2.
Use it only for right-angled triangles.

Area formulas:
- Rectangle: length x width.
- Triangle: 1/2 x base x height.
- Parallelogram: base x height.
- Circle: pi r^2.
- Trapezium: 1/2 x sum of parallel sides x height.

Volume formulas:
- Cuboid: length x width x height.
- Cylinder: pi r^2 h.
- Prism: cross-sectional area x length.

## Graphs And Coordinate Geometry

Gradient of a straight line is rise divided by run. The equation y = mx + c has
gradient m and y-intercept c.

To draw a graph, make a table of values, plot points accurately, join with a
smooth curve or straight line as required, and label axes with scale.

## Statistics And Probability

Mean = total of values / number of values. Median is the middle value after
ordering. Mode is the most frequent value. Range = largest value - smallest
value.

Probability = number of favourable outcomes / number of possible outcomes.
Probability is between 0 and 1. Mutually exclusive outcomes cannot happen at
the same time.

## Common Problem Templates

Solving equation problem:
State the equation, simplify both sides, isolate the variable, divide, and check.

Geometry proof problem:
Write each angle fact with a reason, then conclude the required angle or proof.

Mensuration problem:
Draw or identify the shape, select formula, substitute measurements, calculate,
and add units squared for area or cubed for volume.

Statistics problem:
Organize data first, choose correct measure, calculate carefully, and interpret
the result in words.
