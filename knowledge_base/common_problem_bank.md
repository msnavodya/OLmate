# Common Problem Bank For Chat And Quizzes

Use these patterns to help the bot answer common student requests and generate
quiz questions.

## Universal Answer Formula

Definition -> Key points -> Example -> Exam sentence.

If the student asks "explain", give a clear meaning and two or three supporting
points. If the student asks "compare", use the same criteria for both sides.
If the student asks "why", give causes. If the student asks "effects", give
results. If the student asks "how", give ordered steps.

## Mathematics Problem Types

Equation:
Remove brackets, collect terms, isolate variable, divide, check.

Percentage:
Convert percentage to decimal, multiply by value, interpret as increase,
decrease, discount, profit, or loss.

Geometry:
Draw figure, mark known values, apply angle rule or theorem, give reason.

Statistics:
Order data, choose mean/median/mode/range, calculate, interpret.

## Science Problem Types

Biology process:
Name process, raw materials, place where it happens, products, importance.

Chemistry reaction:
Name reactants, condition, products, observation, word equation.

Physics calculation:
Formula, substitution, calculation, unit, final sentence.

Experiment:
Aim, apparatus, method, variables, observation, conclusion, safety.

## Language Problem Types

Grammar:
Find error, name rule, correct sentence, explain briefly.

Comprehension:
Locate evidence, answer directly, avoid unrelated ideas.

Essay:
Plan three points, one paragraph per point, use linking words, conclude.

Literature:
Text, speaker or character, situation, meaning, technique, message.

## Humanities Problem Types

History cause:
Background, long-term causes, immediate trigger, final result.

History effect:
Political, economic, social, cultural, religious results.

Geography factor:
Physical factors, human factors, economic factors, environmental impact.

Civic problem:
Define issue, causes, effects, citizen duties, solutions.

Religion value:
Teaching, meaning, example, life application, social benefit.

## Quiz Generation Hints

A good MCQ question has one correct answer, three believable wrong answers, and
a short explanation. Avoid trick questions unless the misconception is common.

Good distractors:
- Wrong unit or formula.
- Confused definition.
- Reversed cause and effect.
- Over-general statement.
- Unrelated but familiar term.

Explanation format:
State why the correct option is right, then mention the key idea students should
remember for exams.
