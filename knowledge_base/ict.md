# ICT Knowledge Base

## Exam Answer Pattern

ICT answers should define the term, explain how it works, give a practical
example, and mention advantages, disadvantages, or safety where relevant.

## Computer System

A computer system includes hardware, software, data, users, and procedures.
Hardware is the physical part of a computer. Software is the set of programs
that instruct hardware.

Input devices enter data, such as keyboard, mouse, scanner, microphone, and
camera. Output devices present information, such as monitor, printer, speaker,
and projector.

The CPU processes instructions. Main memory stores data currently being used.
Secondary storage stores data permanently, such as hard disk, SSD, memory card,
and optical disc.

## Software

System software manages the computer and provides a platform for applications.
An operating system manages files, memory, devices, users, and security.

Application software helps users perform tasks such as word processing,
spreadsheets, presentations, databases, browsing, graphics, and communication.

## Data And Information

Data are raw facts. Information is processed data that is meaningful and useful.
Good information should be accurate, relevant, complete, timely, and clear.

Binary uses 0 and 1. A bit is the smallest data unit. A byte usually contains
8 bits.

## Networks And Internet

A computer network connects devices to share resources and communicate. LAN
covers a small area. WAN covers a large area. The internet is a global network
of networks.

Common internet services include web, email, file transfer, messaging, cloud
storage, video conferencing, and online learning.

## Safety And Ethics

Computer security protects data and systems from damage, theft, or misuse.
Threats include malware, phishing, weak passwords, unauthorized access, and
data loss.

Good practices include strong passwords, backups, antivirus, software updates,
careful downloading, privacy settings, and respectful online behaviour.

## Common Problem Templates

Device classification:
State whether it is input, output, storage, processing, or communication and
give its function.

Advantages/disadvantages:
Give at least two clear points for each side with examples.

Flowchart/algorithm:
Identify input, process, decision, output, and order of steps.
